# TwinVM v1.2.101 —— M1 并发：容器 B 独立进程化（真·双活）

## 方案（进程级隔离——案 B 的正解）

stage0 全局态密集（g_live_fd/g_t_pid/g_launch/g_cpu/待办表…）不可
重入——串行靠复位，**并发必须进程隔离**：

```
宿主 App 进程：容器A（stage0 原样，串行语义不变）
  └─ fork → b-runner 进程：容器B（stage0 的独立全局态副本）
              ├─ 自己写 twinvm-live-b.log（写端独立）
              └─ 结果经管道 → 宿主后台线程 → twinvm-b-result.log
```

- B 按钮调 `Native.stage0Parallel`：fork + 子进程内跑 stage0，
  **立即返回**（不阻塞 UI，A 可同时跑）
- 全局态 = fork 快照副本 → 天然隔离，互零污染
- guest 也在 b-runner 里 fork → 各 slot 的 guest/pid/fd 全独立
