# TwinVM v1.2.106 —— 两小遗留清账（banner live 判定 + bwatch 门闩）

## ① B 横幅 live=off 显示瑕疵
banner 的 liveLog 判定原本用 JNI jstring——b-runner 的 C 路径下永远
NULL → 显示 off（实际 live-b.log 写得好好的）。修：jstring 或
g_c_live_path 有值都算 on。顺带修了 banner 只在 g_live_fd>=0 时写的
边角（现在无条件写，stdout 兜底）。

## ② bwatch 误判门闩（"点 B 后 B 栏冻住"的真凶）
启动 1.5s 后读 live-b.log——若 b-runner 还没来得及 O_TRUNC 重写，
读到【上一轮旧日志】（含旧"槽位退出"）→ 误判 B 已完成 → 线程退出
→ B 栏永久静止。
修：记录点击时刻的 mtime——只有文件 mtime 变化（本轮重写发生）后
才开始判终点；没变就显示"等待本轮启动…（Ns）"。
