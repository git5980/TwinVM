# TwinVM v1.2.109 —— M2：运行期安装（手动装 APK 进容器）

> TA 需求澄清后的正解：**TwinVM 本来就是可手动安装的 APK**；
> 真正要做的是"装了 TwinVM 之后，把任意 APK 手动装进容器"——本期交付。

## 新增：⬇ 安装 APK 进容器

```
点 [⬇ 安装 APK 进容器（选文件）]
  → 系统文件选择器（ACTION_OPEN_DOCUMENT，apk mime 优先 /*/ 兜底）
  → 拷贝 pending.apk → Native.installApk()：
      C 侧 ROM 增量重写（读 128MB → 表尾加 inode + 数据区尾对齐追加
      → .tmp 原子替换）——rom_add.py 的运行期 C 版
  → ✅ 提示（/data/app/install-N.apk，ROM 大小）
```

## 关键配套改造

- **romPath() 不再每次覆盖**：demo.rom 只在不存在时从 assets 落地——
  运行期安装的 APK 才能留存（清 App 数据=恢复出厂 ROM）

## 安装后的使用

- 装好的 APK 在容器的 /data/app/install-N.apk
- **入口类名问题**：CLI 跑需要 main 类（M3 的 ActivityThread 模拟后
  才能跑标准 APK）——本期安装即验证（ROM inode 合法+校验通过）
- Via APK 到位后：安装 → M3 开发
