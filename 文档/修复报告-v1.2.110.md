# TwinVM v1.2.110 —— FGS 遗留账连坐闪退（真机 crash 实锤修复）

## 现场（TA 的 crash 日志）

```
15:15:23.33 App 冷启动（PID 7278）
15:15:23.57 FATAL: ForegroundServiceDidNotStartInTimeException
        Context.startForegroundService() did not then call
        Service.startForeground(): ServiceRecord{a7306ac .RunService}
```

冷启动 1.4s 就死——TA 连按钮都没点。**不是本次会话的调用**。

## 根因（链条）

1. 上个会话：点容器 → dispatch 里 startForegroundService(RunService)
2. TA 上滑杀 App → 进程 kill -9（无任何回调）
3. system_server 里 RunService 的 ServiceRecord 留着
   "startForegroundService 已调、未兑现 startForeground" 的账
4. 账有超时（~20s）——但若进程重启（TA 再点图标），新进程 attach
   后 system_server 清算旧账 → 向**新进程**抛
   ForegroundServiceDidNotStartInTimeException → 冷启动即闪退
5. TA 再点容器C（"运行安装的 Demo"）自然也全灭——App 根本起不来

## 修复（三重）

① **manifest：RunService 加 stopWithTask="true"**——杀 App 即停服务，
   不留账（根治）
② **RunService.onCreate 立即 startForeground**（不等 onStartCommand）
   + 全程 try-catch（通知限制不炸服务）
③ **MainActivity.onCreate 冷启动清账兜底**：stopService 一次，
   触发 system_server 关闭可能残留的 record
