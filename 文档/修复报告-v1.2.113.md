# TwinVM v1.2.113 —— 容器C 改造：应用列表（点开看已装 APK，点选运行）

## TA 需求

"C按钮点一下会显示当前虚拟机装了哪些apk，点击apk运行"

## 新交互流

```
[📦 容器C：已装应用（点开选 APK 运行）]
   ↓ 点击
弹窗：容器已装应用（点选运行）
  📦 SampleApp.apk
     com.twinvm.sample.Main          ← 内置映射，点击直接跑
  📦 install-1.apk
     （扫描建议/入口未知）            ← 输入框预填，确认后跑
   ↓ 点选
SampleApp → 直跑（setDex + setMainClass → stage0 → live-c.log）
其他 APK → dex 字符串表扫描建议入口（L…/Main; 优先精确 Main）
         → 无静态 main（Activity 类）→ 输入框输类名（M3 后可跑 Activity）
```

## 实现链

- `Native.listInstalledApks(rom)`：vm_rom_load → 遍历 inode → /data/app/ 前缀
- `Native.extractFile(rom, inner, out)`：ROM inode → 宿主 cacheDir（dex 扫描用）
- Java `suggestMainClass(dex)`：dex header string_ids 表 → 找 "L…Main;" 类
  描述符 → 类名建议（精确 `/Main;` 优先）
- AlertDialog 列表 + EditText 输入（android.app.* 零依赖）
