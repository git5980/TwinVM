# TwinVM v1.2.115 —— 列表两项体验修正（预装标注 + 内部类误报）

## 案情（TA 截图 19:31）

"卸载重装只装了一个 apk 却显示两个"：
1. **SampleApp.apk 是出厂预装**（v1.2.107 起打进 ROM assets 的
   /data/app/）——不是 TA 装的，但列表没说明 → 误解为"幽灵安装"
2. **MainActivity$1 误报**：suggest 扫到匿名内部类（OnClickListener）
   排在真正入口前——显示 com.twinvm.demo.MainActivity$1 很怪

## 修复

1. 列表项标注 `[预装]`（SampleApp / TwinVM-M2-DemoApp——assets 出厂件）
2. suggest 排除 `$` 内部类（MainActivity$1 不再入选）
3. 标题带计数："容器已装应用（N 个 · 点选运行）"

## 验证
make test 5/5；APK **265/1.2.115 SIGN_OK**

   [预装] SampleApp.apk / com.twinvm.sample.Main
   [预装] TwinVM-M2-DemoApp.apk / com.twinvm.demo.MainActivity（无 $1）
   install-N（TA 装的，无预装标）→ CliMain 建议（新 DemoApp v2 才有）
