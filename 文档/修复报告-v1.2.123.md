## 本版：诊断增强（Bootstrap v2）

Bootstrap 加【ClassLoader 结构透视】（反射 DexPathList.dexElements）：

```
M3-CL: 层级 com.android...PathClassLoader -> ...(元素列表)
M3-pathList: ...
M3-elements: N
M3-elem[0]: ...（DexFile 路径——apk 段在不在、是什么形态）
M3-elem[1]: ...
```

若 apk 段缺失 → -cp 双路径解析问题（分隔符/元素拆分）

若两段都在 → 类查找逻辑问题（sizes 不可读等）
