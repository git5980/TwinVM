# TwinVM v1.2.128 —— M3 第六案：构造器 stub 雷绕行（Unsafe 裸分配）

## 案情（20:56 live-c.log——framework 补全后大跃进）

```
M3-dexfile: loadClass = class com.twinvm.demo.MainActivity  ✓✓✓
M3-Bootstrap: 类装载 OK：com.twinvm.demo.MainActivity      ✓✓✓
  ← framework.jar 生效！类装载与父类解析全通！

M3 异常: RuntimeException: Stub!（实例化时）
  at android.content.Context.<init>(Context.java:23)
  at android.content.ContextWrapper.<init>(Context.java:23)
  at android.view.ContextThemeWrapper.<init>
```

## 定罪

MainActivity 无参构造 → super 链一路到 Context.<init> →
android.jar 的 stub 方法体抛 "Stub!"（预期内的雷）。

## 修复（Bootstrap v6：Unsafe.allocateInstance 裸分配）

构造器炸 → 纯反射拿 sun.misc.Unsafe（ROM 的 core-oj 里有真实现）→
allocateInstance 裸分配实例（跳过一切构造器）→ 生命周期方法反射照调。

（sun.misc 不在 android.jar API 面——用字符串类名 Class.forName 反射，
ECJ 编译通过。）
