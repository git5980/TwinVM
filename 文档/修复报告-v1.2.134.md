# TwinVM v1.2.134 —— attach 签名自适应（Android 16 的 attach ≠ 12 参）

## 案情（10-25 06:31 日志）

```
M3-Bootstrap: attach 异常: NoSuchMethodException: attach(12参) 未找到
  ← attach 这次【真的跑了】（v9 汇合点修复兑现）
  ← 但 TA 的 Android 16（API 36）framework 里 attach 参数数 ≠ 12
```

（API 34 是 12 参；TA 提取的 API 36 件签名有变化。）

## 修复（Bootstrap v10：签名自适应）

```java
attach 查找：按名匹配【任意参数个数】（≥8 参的实例方法）
命中后打印实际签名（诊断行：M3-attach: 签名 N 参: …）
参数按位组装：
  Context        → 动态代理
  有无参构造的类  → newInstance（ActivityThread/Instrumentation/Application/…）
  IBinder/CharSequence 等 → null
  原始类型       → 默认值
```

## 预期剧本

```
M3-attach: 签名 N 参: protected void android.app.Activity.attach(...)  ← 真实签名
M3-Bootstrap: attach 完成（最小 Context 注入）
→ 五段 super 走真实现 → 下一个雷（预计 setContentView 的 Window）
或 attach 内部炸（ActivityThread 构造等）→ M3-attach-因 三帧
```
