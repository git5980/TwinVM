```
                                               ContextWrapper 转调 mBase=null
```

## 根因（版本错位）

- bootstrap.jar 用 API 34 android.jar 编译——API 34 的 Context **没有**
  setAutofillClient（那是 API 35+）
- TA 的 Android 16（API 36）framework 有 → 运行时 attach 调它 →
  MiniContext（v13 前=ContextWrapper）没有覆写 → 转调 null base → NPE

## 破局（dex 描述符级占位）

```
手写占位接口 android.view.autofill.AutofillManager$AutofillClient {}
（空接口——描述符 Landroid/view/autofill/AutofillManager$AutofillClient;
  与 TA 真 framework 完全一致——dex 运行时按描述符互认）

MiniContext extends ContextWrapper：
  setAutofillClient(占位) → {} 空实现   ← 覆写在！
  getAutofillClient()    → null
  + 预防性覆写：getApplicationContext/getSystemService/getPackageName/
    startActivity/registerReceiver/getSharedPreferences(全接口实现)/
    getClassLoader/getFilesDir 等

attach 的 Context 参数 → MiniContext（不再 ContextWrapper）
（@Override 去除——API34 编译期父类无此方法，运行时描述符匹配即生效）
```
