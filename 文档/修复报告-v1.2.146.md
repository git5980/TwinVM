```
Exception in thread "tvm-main":
  ExceptionInInitializerError
    at android.os.HandlerThread.run(HandlerThread.java:77)
  Caused by: NPE: com.oplus.reflect.RefConstructor.newInstance() on null
    at android.os.ZygoteProcess.<init>(ZygoteProcess.java:177)
```

**完整链**：runFlow 中触碰 android.os.Process 类 → 静态块 →
ZygoteProcess 构造 → OnePlus 的 RefClass 反射加速加载
ExtPlugin → 容器环境下 RefConstructor 拿到 null → NPE。
（[LC] 行可见 RefClass 的装载日志——桥透传的）

## 本版（诊断强化 + 结构换道）

1. runFlow 全程打点：M3-flow 进入/退出（区分卡/炸粒度）
2. HandlerThread → 普通 Thread + 手动 Looper.prepare()（真机等价物，
   绕开 HandlerThread 类链）
3. main 的流程异常打印补五帧（之前 err.set 了但没打全栈）
4. Looper.loop() 在 runFlow 后自然收尾
