# TwinVM v1.2.151 —— 云端管道（TA 提议：日志直传 + 热更新）

## 架构（TA 的 DevOps 化建议落地）

```
┌ TA 手机                          ┌ 沙箱服务器（阿里云 47.95.253.127:8765）
│ [☁ 云端] 按钮 ──────────────→   │ /healthz   连通测试
│  ① 连通检查                      │ /log/<name> 收日志（live + archive 全部）
│  ② 上传全部日志（live/*.log +    │ /patch/meta 热更清单（JSON：md5+ROM内路径）
│     archive/*.log）              │ /patch/<name> 补丁本体（bootstrap.jar/
│  ③ GET 热更清单 → md5 校验 →     │              libtvmbridge.so）
│     vm_rom_replace 替换 ROM 内文件│
│  ④ 下次启动容器 = 新代码生效      │ （我这边改完补丁直接放 patches/ ——
│                                  │   TA 重跑容器即可，无需装 APK！）
```

## 关键实现

- **vm_rom_replace**（引擎层新增）：ROM 内同路径 inode 覆盖式替换
  （主机全链验证：异尺寸替换 ✓ 还原 ✓ 全 CRC ✓）
- App 侧 HTTP（零依赖 HttpURLConnection）+ org.json（系统自带）
- manifest：INTERNET + cleartext（HTTP 明文）

## 迭代节奏变化

```
旧循环：改 bootstrap → 重打 APK → 发 → TA 装 → 跑 → 导日志 → 发我（30-60 分钟/轮）
新循环：改 bootstrap → 放服务器 patches/ → TA 手机点 [☁ 云端]
       → 补丁进 ROM → 重跑容器 → 日志自动直达我（~2 分钟/轮）
```
