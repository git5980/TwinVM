# TwinVM v1.2.155 —— 热更通道最终形态（@hotfix-latest 滚动 tag）

## TA 问"删掉旧文件行吗"的实测答案

```
实测：仓库删除文件后 CDN 仍 200 返回旧内容（缓存不透删除）——
删除不仅无效还会 404 断供（缓存过期后）。
```

## 三个实测发现（CDN 行为全摸清）

```
① @main 分支引用：仓库 >50MB 后直接 403（"Package size exceeded"）
  ——之前能 200 是仓库还没超（framework 大文件历史推上去后超了）
② @tag 引用：不受 50MB 限制（tag 快照直取）✓
③ 固定 tag 名（hotfix-latest）+ force-move：
  CDN 立即拿到新内容 ✓（实测 v20 md5 匹配）
```

## 最终形态

```
源序：raw（无缓存）→ jsdelivr @hotfix-latest（滚动 tag）
发布器：tools/publish-hotfix.sh（一键：版本化文件名 + meta 更新 +
  commit + tag hotfix-<时间戳> + force-move hotfix-latest）
版本化文件名：bootstrap-<时间戳>.bin（新名=新缓存键，双保险）
长按 [☁]：tag 逃生门（万一 tag 被缓存层拦住，手动输最新 tag 名）
```
