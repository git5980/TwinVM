# TwinVM v1.2.41 —— ★★★★★ 属性系统复活：PreSplit 单文件属性区合成（bionic 源码逐字段复刻）

> 输入：v1.2.40 真机日志（6.5MB / 75598 行）。

## 一、v1.2.40 真机判读

- ✓ public.libraries.txt 读到了（fd=10000 [ROM]）——上轮修复生效；
- ✗ 新断言（sp+0x240 解码）："Failed to get system property
  **ro.dalvik.vm.native.bridge**"——guest 的 bionic 属性系统初始化失败：
  `openat("/dev/__properties__") → ENOENT`（宿主文件系统不可见）；
- 前置连锁：`nativebridge: Failed to get system namespace for loading
  ld-android.so`（property 死 → native bridge 路径异常）。

## 二、根因（bionic android16-release 源码判读）

`SystemProperties::Init("/dev/__properties__")`：
- `is_dir("/dev/__properties__")` 失败（我们 ENOENT）→ 走 **ContextsPreSplit
  老路径：把 /dev/__properties__ 当单个属性文件打开**；
- `map_fd_ro(fd)` 校验链：fstat 要求 **uid==0 && gid==0 && 无组写 &&
  st_size ≥ 128**；mmap(PROT_READ, MAP_SHARED)；magic==0x504f5250、
  version==0xfc6ed0ab。

## 三、修复：合成 PreSplit 属性文件（tools/gen_props.py）

- **格式逐字段复刻**（源码核对）：头 128B（bytes_used_/serial=0/magic/
  version/reserved[28]）+ trie 节点（namelen|prop|left|right|children|name[]，
  4 字节对齐，root 在 data_+0）+ prop_info（serial=valuelen<<24|value[92]|name[]）；
- **查找算法同构**（分段 → children BST strcmp 序，右斜树构造）+ **离线校验器**
  （模拟 bionic walk，9/9 属性通过）；
- 属性集：ro.dalvik.vm.native.bridge=""（本 FATAL 直接需求）+ heapsize/
  growthlimit/startsize/usejit/sdk=36/release=16/appimageformat 等 9 条；
- **挂进 ROM**：/dev/__properties__（1856B）——引擎合成 fd 的 fstat 天然
  uid=0/gid=0（memset 0）+ ROM 文件 mode 无组写 + mmap-fill 现成机制
  （boot.oat 同款）。

**ROM md5: 297c0f8b → d368e4e4**（v1.2.41 起以此为准）。
