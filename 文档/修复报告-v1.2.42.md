## 二、符号化定罪（ROM 反汇编）

- 断言串在 **libnativebridge.so+0xf80**：`"Failed to get system namespace for
  loading %s"`（%s=ld-android.so）；
- 调用者 **OpenSystemLibrary+0xac**（+0x2044 起）：
  ```c
  ns = android_get_exported_namespace("system");   // 主查询（串 @0x163d 实测）
  if (!ns) ns = android_get_exported_namespace("default");  // 兜底
  if (!ns) LOG(FATAL) ...;                          // "system_ns == nullptr"
  → android_dlopen_ext(name, flags, {ANDROID_DLEXT_USE_NAMESPACE=0x200, ns})
  ```
- 兄弟断言：**libart.so+0xcc71f** "Failed to get system namespace for loading
  OAT files"（同源，下一步会撞上）；
- 根因：我们 ROM 的 /system/etc/ld.config.txt **没有一处 visible=true** →
  g_exported_namespaces 空表 → 两个查询全 NULL → FATAL。

## 三、源码核对（bionic linker，aosp-ref 在手）

- linker.cpp:3673/3692：`if (default_ns_config->visible())
  g_exported_namespaces[...] = ...`——**只有 visible 才注册导出表**；
- linker_config.cpp:561：配置键 = `namespace.<name>.visible = true`
  （".visible" 字面量被编译器内联成立即数，strings 搜不到——坑记入）；
- 配置回退序（linker.cpp 常量）：/linkerconfig/ld.config.txt（宿主不可见）
  → **/system/etc/ld.config.txt（我们 ROM 的，实读在案）**。
