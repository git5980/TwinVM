# TwinVM v1.2.44 —— ★★★★★ 配置被整份判无效的真相：links 行缺 shared_libs（上轮警告一直就在日志里）

> 输入：v1.2.43 真机日志（4MB / 47681 行）。

## 一、v1.2.43 判读：realpath 修复**生效**

- `openat("/proc/self/exe") -> fd=10000 [ROM 真身 /system/bin/dalvikvm]`（新探针命中）；
- realpath 链完整走通（newfstatat("/system/bin/dalvikvm") 出现=真身已解析）；
- 但断言仍在，且 **日志里抓到了之前漏掉的警告**（搜词修正后现形）：
```
Warning: couldn't read '/system/etc/ld.config.txt' for '/system/bin/dalvikvm'
(using default configuration instead):
/system/etc/ld.config.txt:19: error: list of shared_libs for system->art link
is not specified or is empty.
```

## 二、根因

v2 配置声明了 `namespace.system.links = art` 但没配
`namespace.system.link.art.shared_libs`——linker_config.cpp 的校验（"list of
shared_libs for X->Y link is not specified or is empty"）把**整份配置判无效**
→ 退回 no_config → g_exported_namespaces 恒空 → 断言。
（本轮教训：我读过那段校验源码却没对照自己写的配置自查。）

## 三、修复（v1.2.44：ld.config.txt v3）

- **删掉 links 行**，把 art 的库路径并入 system/default 的 search.paths
  （/apex/com.android.art/lib64）——一个 namespace 搞定，无链接对；
- visible 四处保留；属性文件保留；
- **ROM md5: 894db1ad → 727593aa**（69 inodes）。

## 四、验证

make test 5/5；checkrom --strict PASS；APK **194/1.2.44 SIGN_OK**；包内 ROM 一致。

1. **无 "couldn't read" 警告**（配置有效性的直接观测）；
2. 无 "Failed to get system namespace" + 无 [sig] signal 6；
