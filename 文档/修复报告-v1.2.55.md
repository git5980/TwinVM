# TwinVM v1.2.55 —— 优雅关机 + 消音 + 压力测试 dex（Hello 后第一版）

> 基于 v1.2.54（Hello 里程碑）的后续三合一。

## 一、优雅关机（Signal Catcher sigwait 原生化）

**定罪**：137（rt_sigtimedwait）在 ptrace 后端的 `tvm_virt_nr` 拦截表里——
tracer 在**自己进程**用 guest 的地址参数执行 sigtimedwait（进程错位）→
EPERM → "signal_set.h:61] sigwait failed" → 收尾 abort。

**修复**：拦截表移除 case 137 → **guest 原生执行**（参数地址有效、阻塞在
guest 自己身上）。Runtime 收尾的 tgkill(SIGQUIT) 本就原生投递（131 不在
拦截表）→ 信号真正唤醒 sigwait → Signal Catcher 正常走 Shutdown 流程。

## 二、消音（两处）

1. **PR_SET_NAME**：prctl(15) 伪造成功——"Unable to set the name of
   current thread" ×14 消失（线程名对 guest 只是自我标签）；
2. **faccessat W_OK 修正**：ROM 文件无写位 → access(W_OK)=EACCES——
   "Attempt to load writable dex file" 警告消失（ART 不再走降级校验）。
