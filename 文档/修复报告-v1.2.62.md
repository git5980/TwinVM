## v6 修复（架构级）

**判定搬到 tracer 线程**——它是永不退场的示踪者，guest 每个停点都经它的手：
1. 判定核心抽成 `tvm_graceful_check()`（停点驱动 + 静默驱动共用）；
2. waitpid 阻塞式 → **WNOHANG + 10ms 轮询**（真静默期 tracer 醒着驱动检查；
   忙时几乎总是直接命中停点，吞吐无损）；
3. 触发 → SIGTERM → 2s → SIGKILL → g_t_done=1 退出示踪循环 → join 返回
   → stage0 返回 → UI 回到结果页。

主线程死活从此无关——就算它再死一次，tracer 也能独立收场。
