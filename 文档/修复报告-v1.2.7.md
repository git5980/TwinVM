## 2. 新卡点（两个，都已实证）

### ① /proc/self/maps 合成 0 条（synth 34B）
v1.2.6 日志原文：`openat("/proc/self/maps") -> fd=10060 [synth 34B, 0 maps]`。
旧方案从 g_vmmaps 记账表渲染（exec_dyn 初始映射），**ptrace 后端的库映射全走
tracer 的 mmap-fill——引擎侧一条都记不到**（教训五第三实例：记账器与
执行者不在一个进程）。ART/unwinder 拿到空 maps 会走退化路径。

### ② /sys/devices/system/cpu/possible ENOENT
死前最后一个成功路径请求是它（ART 规划 GC 线程池的 CPU 拓扑），ENOENT 后
仅剩 stat/maps 两个请求，随后 socket 静默——像是在等一个永远不会来的响应。
