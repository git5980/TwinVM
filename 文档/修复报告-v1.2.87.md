## 定罪（linker64 反汇编 + 段归属双重验证）

```
lr → linker64 vaddr 0x9ffb0/0x9fff4 = __dl___cxa_atexit 内部！
调用点：9ffac（RW 改写）、9fff0（恢复 R）
0x78d3ab8000 = libart.so 的 ELF 头/RELRO 页（fd=10000 fill 段 off=0）
```

**案情**：Android16 linker 的 `__cxa_atexit` 实现对【已 RELRO 的
.data.rel.ro 页】做"临时 RW → 写登记 → 恢复 R"——每次调用一对 mprotect。
循环期 50 次/秒 mprotect = **上层有人每秒 25 次循环调 __cxa_atexit**。

（v1.2.86 的 x23 解读修正：在 cxa_atexit 帧里 x23=soinfo 指针——
"构造函数"的指认作废，真正的循环调用者待帧链定位。）
