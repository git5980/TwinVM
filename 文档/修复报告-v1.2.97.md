# TwinVM v1.2.97 —— 容器B 三 Bug 修复（TA 实测反馈）

## TA 报告的现象
1. 自检结束后日志上的计时器不停
2. 点"运行容器B"，计时器**交替闪烁**

## 定罪（三个独立 bug）

### ① 容器B 根本没跑！（致命）
```java
result = isRun ? Native.stage0(...) : Native.probe();   // 只判 isRun
```
isRunB ≠ isRun → 点 B 走了 `probe()`（引擎探测秒回）——dex 没跑。
所以 TA 看到的"B 很快结束"其实是探测输出。

### ② 计时器不停
stage0 的 ART 收尾期长达 240s（兜底在等）——期间 ticker 一直
刷"已运行 N 秒"。补**终点线检测**：日志出现 "-pass in" 或"槽位退出"
后 15 秒 → ticker 提前收摊。

### ③ 交替闪烁
旧 ticker（A 的 400ms 循环）没死透，新 ticker（B 的）又起——
两个循环抢刷同一个 mOut。修复：**ticker 代际制**（静态计数器，
新一代启动 = 旧一代自然退出）。
