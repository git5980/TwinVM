# TwinVM v1.2.99 —— 容器身份横幅（答"为啥容器B日志和自检一样"）

## TA 疑问的答案（两层）

1. **如果跑的是 v1.2.96 的 B**：那是 isRunB→probe() 的 bug（v1.2.97 已修）
   ——当时 B 压根没跑 dex，显示的是引擎探测输出。

2. **如果已是 v1.2.97+**：日志【前 99% 确实一样】——因为两个容器用的是
   同一套 ROM/装载/引擎流程，区别只在【末尾的 Java 输出段】（10 行）：
   - 容器A：hello TwinVM from ART / loop-sum / ... / stress-all-pass
   - 容器B：world TwinVM 容器B from ART / primes / palindromes / ...
   14k 行日志里 Java 段在最后，开头横幅全同——"看起来一样"是视觉误会。

## v1.2.99：容器身份横幅

日志第一行立刻可辨：
```
[TwinVM] ══ 容器启动 ══ dex=/rom/world.dex ══ live=on ══
```

（B 的日志文件名也是独立的 twinvm-live-b.log——注意别看串文件。）
