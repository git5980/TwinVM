## 二、本次修复

### 2.1 MiniPackageManager（94 个抽象方法，生成）

新增 `com.twinvm.m3.MiniPackageManager`（`tools/gen_pkgmgr.py` 从 android.jar
的 PackageManager 抽象方法表生成），语义：

- `hasSystemFeature(...)` → false（Button/TextView 的 Wear/Material3 分支直接走否）
- `getPackageInfo/getApplicationInfo` → 最小 PackageInfo/ApplicationInfo（包名/版本/uid）
- `getInstalledPackages/Applications`、`query*` → 空列表
- `checkPermission` → `PERMISSION_DENIED`
- 其余按返回类型给安全默认值（详见生成文件）

`MiniContext.getPackageManager()` 改为懒加载返回该壳（不再 null）。

### 2.2 v94b 壳链改用 Activity 上下文

`Bootstrap.manualAttach` 中 PhoneWindow 的 `mContext`、`PhoneLayoutInflater`、
`mContentParent = new FrameLayout(...)` 全部从 `MiniContext` 改为 **Activity**
（Activity 有 `getTheme()`，`LinearLayout/TextView` 此前就是用它构造成功的）。
这样 mDecor/mContentParent/mWindow 三件套能真正落地，setContentView 有容器可加。

### 2.3 补齐 ROM 缺失 native（75 条）

`tools/gen_missing.py` 对比 ROM `framework.dex` 与现有注册表，只补"ROM 有、桥缺"的：

| 类 | 本次补 | 说明 |
| --- | --- | --- |
| SystemProperties | 重写整表 12/12 | 双 API：`native_find(String)J` + `native_get(J)` handle 族（新链必需） |
| Trace | +8 | nativeInstant / AsyncTraceForTrack / SetTracingEnabled 等 |
| SystemClock | +1 | currentTimeMicro |
| Binder | +15 | clearCallingIdentity / restoreCallingIdentity / getThreadStrictModePolicy 等 |
| BinderInternal | +8 | **handleGc()V**（本次 finalizer 报错）、setMaxThreads 等 |
| EventLog | +2 | readEvents / readEventsOnWrapping |
| MessageQueue | +1 | nativeIsPolling(J)Z |
| AssetManager | +12 | XmlAssetFd/GetResourceBagValue/SetConfiguration/AttributeResolutionStack 新签名等 |
| Typeface | +1 | nativeIsVariationInstance |

补齐后 SystemProperties 12/12；其余类的"旧表 + 补充表"并集与 ROM 一致。
