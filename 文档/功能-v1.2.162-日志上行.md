# v1.2.162 —— 日志上行通道（TA 13:07 提议："借鉴热更方式把日志实时上传"）

## 设计

```
方向：App → GitHub logs 分支 → 我直接拉（TA 不再手动传 zip）

App 侧：
① 长按 [☁ 热更新] → 对话框现在两个输入框：
   - tag（热更逃生门，原有）
   - GitHub PAT（新——日志上行用）
② 容器跑完（终点存档的同一时机）自动 PUT：
   PUT api.github.com/repos/git5980/TwinVM/contents/logs/twinvm-live-c.log
   {message, content(base64), branch:"logs", sha?}
   （>900KB 截尾；GET 旧 sha 后更新——同文件覆盖不炸）
③ token 存 SharedPreferences（重启保留）

我侧（拉取）：
   raw.githubusercontent.com/git5980/TwinVM/logs/logs/twinvm-live-c.log
   （raw 无 CDN 缓存——实时）
```

## TA 需要做的（一次性）

```
① 到 github.com/settings/tokens 生成 fine-grained PAT：
   - Only select repositories: TwinVM
   - Permissions: Contents → Read and write
② 装上 v1.2.162 后长按 [☁ 热更新] → 把 PAT 贴进第二个框 → 确定
③ 以后每轮容器跑完日志自动上——我直接拉，不用你再传
```

## 安全说明

```
PAT 只授予 TwinVM 单仓库的 contents 写权限——泄露面最小
（写不了别的仓库、动不了设置）
```
